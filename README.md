# Реестр договоров

Простой демонстрационный реестр на HTML и JSON без авторизации и базы данных.

## Запуск

```powershell
docker compose up --build
```

Открыть: <http://localhost:8082>

Данные сохраняются в `data/data.json`. Каталог подключен к контейнеру как volume,
поэтому изменения не теряются после перезапуска.

Для запуска без Docker:

```powershell
python server.py
```

## Состав

- обзор лимитов и фактических доходов/расходов;
- реестр договоров с поиском и фильтрами;
- платежи и поступления, связанные с договорами;
- контроль превышения договорного лимита;
- простая аналитика по проектам и остаткам;
- редактирование записей непосредственно в табличных строках;
- история последних 50 изменений и восстановление состояния;
- один JSON API: `GET /api/data` и `POST /api/data`.

Статические файлы интерфейса сервер отдает отдельно. Все прикладные данные читаются
и сохраняются через единственный API-адрес `/api/data`.
